# `pr/ftp`

One part of the topic repo p1ngb4ck/esphome-storage-drivers. The whole topic, with its description, is the branch `main`.

Change of this branch: `ftp`: FTP / FTPS / TFTP clients as network storages, an FTP server and a TFTP server on a storage

Based on these branches, whose changes it holds and builds on:

- `pr/cert-store` of p1ngb4ck/esphome-cert-store: `cert_store`: CA, client certificate and key per TLS client - embedded, from a storage, or by name from a folder, Home Assistant or HTTP sources; the CA bundle as fallback
- `pr/storage-write-done` of p1ngb4ck/esphome-storage-interface: `write_done()`: a storage is told when a written file is complete (network storages finish uploads there)
